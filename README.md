# Rucha Agnihotri — Portfolio

Personal portfolio website hosted on GitHub Pages.

**Live Site:** https://ruchaagnihotri.github.io

## Stack
- Pure HTML, CSS, JavaScript — no frameworks, no build tools
- Google Fonts: Syne + DM Sans + DM Mono
- Fully responsive

## Setup

1. Clone or download this repo
2. Upload your CV as `documents/Rucha_Agnihotri_CV.pdf`
3. Push to a GitHub repo named `ruchaagnihotri.github.io`
4. Go to **Settings → Pages → Source: main** → Save
5. Site goes live at `https://ruchaagnihotri.github.io` in ~2 minutes
